# 🧠 ورزش ذهن — Zehn Exercise

**Anti AI Game Eitaa** — یک اپلیکیشن تک‌فایلی و کاملاً کلاینت‌ساید برای ورزش مغز و تقویت حافظه، تمرکز و سرعت فکر.

استفاده‌ی زیاد از هوش مصنوعی مغز را تنبل می‌کند؛ این اپ با ۸ بازی آموزشی، ذهن را به فکر کردن و یادآوری وادار می‌کند. بدون سرور، بدون اینترنت و بدون وابستگی — کاملاً کلاینت‌ساید.

## ✨ امکانات

- **۸ بازی آموزشی** درباره‌ی ایران: شهرها، جاذبه‌های طبیعی، غذاهای محلی، مشاهیر، صنایع دستی، ضرب‌المثل‌ها، حساب سریع و حرم‌شناسی
- **۳ سطح** (ساده / متوسط / سخت) با قفل و بازشدن خودکار سطح‌های بالاتر
- **ذخیره‌ی امتیاز و رکورد** در `localStorage` مرورگر
- **صداهای تعاملی** ساخته‌شده با Web Audio API (بدون فایل صوتی)
- **موسیقی پس‌زمینه** با پخش حلقه‌ای و کنترل از تنظیمات
- **پنل تنظیمات** برای روشن/خاموش کردن صدای بازی و موسیقی و پاک کردن امتیازها
- **جلوه‌های کانفتی و بازخورد بصری** هنگام پاسخ درست
- **رابط کاربری فارسی و راست‌به‌چپ** با فونت Vazirmatn و طراحی موبایل‌محور
- **فرم بازخورد/گزارش خطا** (Google Apps Script) برای ارسال پیام و پیشنهاد سؤال
- **بدون وابستگی خارجی** (به‌جز فونت گوگل) — فقط HTML، CSS و JavaScript

## 🏆 سیستم امتیاز و سطح

- هر بازی با یک سطح انتخاب‌شده شروع می‌شود: **ساده** (۷ سؤال)، **متوسط** (۹ سؤال) و **سخت** (۱۱ سؤال).
- با گرفتن **بیشتر از ۵ پاسخ درست** در هر دور، سطح بعدی باز می‌شود.
- امتیاز کل، تعداد بازی‌ها، رکورد پاسخ درست و طولانی‌ترین زنجیره‌ی درست در مرورگر ذخیره می‌شود.
- از دکمه‌ی گوشه‌ی بالای صفحه می‌توان در میانه‌ی بازی سطح را عوض کرد.

## 🚀 اجرا

نیازی به build یا نصب نیست. کافی است فایل را باز کنید:

```bash
# کلون کردن پروژه
git clone https://github.com/mohsen-najafzadeh/antiaigameeitaa_app.git

# باز کردن مستقیم
start index.html      # ویندوز
open index.html       # مک
xdg-open index.html   # لینوکس
```

یا یک وب‌سرور ساده اجرا کنید:

```bash
python -m http.server 8000
# سپس http://localhost:8000 را باز کنید
```

## 🌐 انتشار (GitHub Pages)

این مخزن شامل ورک‌فلوی آماده‌ی GitHub Actions است (`.github/workflows/static.yml`). با هر push روی شاخه‌ی `main`، محتوای مخزن به‌صورت خودکار روی GitHub Pages منتشر می‌شود.

## 🛠 پیکربندی فرم بازخورد

فرم بازخورد پیام‌ها را به یک **Google Apps Script** ارسال می‌کند. برای فعال‌سازی:

1. یک Apps Script بسازید و آن را به‌صورت Web App منتشر کنید (دسترسی: Everyone).
2. مقدار `FEEDBACK_DEPLOY` در `assets/app.js` را تنظیم کنید؛ هم Deployment ID و هم آدرس کامل `/exec` پذیرفته می‌شود.
3. در صورت نیاز، مقدار `FEEDBACK_SECRET` را تغییر دهید.

```js
const FEEDBACK_DEPLOY = '<DEPLOYMENT_ID_OR_FULL_EXEC_URL>';
const FEEDBACK_SECRET = 'zehn_avar_2024';
```

## 🧩 توسعه

داده‌های سؤال‌ها در `assets/questions.js` (آرایه‌های `CITIES`، `NATURE`، `FOODS`، `FAMOUS`، `CRAFTS`، `PROVERBS` و `HARAM`) و منطق اپ در `assets/app.js` قرار دارد:

- `GAMES` — ثبت بازی‌ها و سازنده‌های سؤال (`makeCityQuestions`، `makeMathQuestions` و …)
- `startQuiz()` — موتور اصلی مسابقه، امتیازدهی و نمایش نتیجه
- `addScore()` / `loadUser()` / `saveUser()` — مدیریت ذخیره‌سازی امتیاز
- `LEVEL_NAMES` / `LEVEL_COUNT` / `PASS_THRESHOLD` — تنظیمات سطح‌ها

برای افزودن بازی جدید: داده‌های آن را در `assets/questions.js` اضافه کنید، یک تابع `make...Questions` بنویسید، آن را به `GAMES` اضافه کنید و در `getGameSubtitle` توضیح کوتاه آن را وارد کنید.
